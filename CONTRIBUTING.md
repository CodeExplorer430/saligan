# Contributing to SALIGAN

Read `AGENTS.md` before work. It is canonical for human and AI-assisted contributions.

## Workflow

1. Link work to an accepted requirement, issue, ADR, or maintainer instruction.
2. Create a short-lived branch from `main`.
3. Keep changes scoped and source files below 500 lines.
4. Add tests and update documentation.
5. Run required quality gates.
6. Open a pull request using repository template.

Use Conventional Commits and follow:

- `docs/engineering/BRANCHING-STRATEGY.md`;
- `docs/engineering/COMMIT-CONVENTIONS.md`;
- `docs/engineering/REVIEW-CHECKLIST.md`;
- `docs/engineering/DEFINITION-OF-DONE.md`.

Never submit secrets, production data, student records, private attachments, or content you lack rights to license under AGPL-3.0-or-later.
