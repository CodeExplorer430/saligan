# ADR-0001 — Project Identity

## Status

Accepted

## Context

The project needs a Filipino-rooted name that still reads clearly in English documentation and open-source repositories.

## Decision

Use **SALIGAN** as the canonical product name.

SALIGAN expands to **Student Attendance, Logbook, Internship Goals, Accomplishments, and Notes** and is paired with the subtitle **An Offline-First, Self-Hosted Internship Records and OJT Management Platform**.

## Consequences

- All docs, diagrams, OpenAPI specs, package metadata, and prompts use SALIGAN.
- The repository slug is `saligan`.
- The package scope is `@saligan`.
